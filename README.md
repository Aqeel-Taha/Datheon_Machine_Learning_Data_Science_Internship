# Datheon_Machine_Learning_Data_Science_Internship
Machine Learning and Data Science Internship projects featuring Python-based data analysis, classification models, data preprocessing, model evaluation, and data visualization.
## Projects Completed

### Task 1: Multi-Class Benchmark Classification Pipeline

- **Dataset:** Iris Dataset
- Performed Exploratory Data Analysis (EDA) and data visualization.
- Applied Standard Scaling and an 80:20 train-test split.
- Implemented Logistic Regression and Decision Tree classifiers.
- Evaluated models using Accuracy, Precision, Recall, and F1-score.
- Created confusion matrices and decision-boundary visualizations.

### Task 2: Real Estate Housing Price Prediction

- **Dataset:** California Housing Dataset
- Performed data cleaning and missing-value treatment.
- Created interaction features.
- Examined correlation and multicollinearity.
- Implemented Ordinary Least Squares (OLS), Ridge, and Lasso regression.
- Evaluated models using RMSE, MAE, and R².
- Generated actual-versus-predicted and residual plots.

### Task 3: Customer Churn Prediction

- **Dataset:** IBM Telco Customer Churn Dataset
- Performed data exploration and preprocessing.
- Applied One-Hot Encoding and Standard Scaling.
- Addressed class imbalance using balanced class weights in Random Forest.
- Implemented Random Forest and XGBoost classifiers.
- Evaluated models using Accuracy, Precision, Recall, F1-score, and ROC-AUC.
- Generated confusion matrices, ROC curves, and feature-importance visualizations.

### Task 4: NLP Sentiment Classification

- **Dataset:** Customer Reviews Dataset
- Performed text cleaning and preprocessing.
- Applied TF-IDF for text feature extraction.
- Implemented a Multinomial Naive Bayes classifier.
- Developed a function to predict sentiment for new customer reviews.
- Classified reviews into Positive, Negative, and Neutral categories.

**Note:** The supplied customer reviews dataset contains only 10 records. Therefore, this project demonstrates the NLP workflow, but its predictions are not intended to represent reliable real-world model performance.
